# Arroyyan99 POS System

Sistem POS (Point of Sale) berbasis website untuk perusahaan AMDK (Air Minum Dalam Kemasan) Arroyyan99 yang dirancang untuk membantu proses pengelolaan distribusi, transaksi, dan monitoring data secara digital.

Project ini menggunakan konsep multi-role dengan dua sistem utama:

- **Admin (Pabrik)**  
  Digunakan untuk mengelola data produk AMDK, distributor, transaksi, laporan, serta monitoring distribusi.

- **Distributor**  
  Digunakan untuk proses distribusi AMDK, pengelolaan pemesanan, transaksi penjualan, dan aktivitas distribusi lainnya.

## 🚀 Teknologi yang Digunakan

Project ini dibangun menggunakan teknologi modern, di antaranya:

- React.js
- TypeScript
- Vite
- Supabase
- TailwindCSS
- Material UI

## 📌 Tujuan Project

Project ini dibuat untuk membantu digitalisasi sistem distribusi dan penjualan AMDK agar proses operasional menjadi lebih cepat, efisien, dan terstruktur.
